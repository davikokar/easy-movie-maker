Notes

  1. 1Presets only. The list comes from the capability profile. Unsupported presets stay visible but disabled, with the reason. Size estimates come from preset bitrates.
  2. 2Pending work. Jobs the export needs are listed before it starts, so a long wait isn't a surprise.
  3. 3Progress. Steps, then frame-based progress and time left. Cancel deletes the partial file. On Android this is a full screen that must stay in the foreground.
  4. 4Relink. Opens when a project has missing files, or from the status bar. Matches found by fingerprint are pre-selected.
  5. 5Failure messages say what happened, why, and what to try, and confirm that nothing changed. The calculation is available but collapsed.
  6. 6Recovery appears at startup when the autosave copy is newer than the saved file.
  7. 7Diagnostics never block preview or export. Each one links to the fix.
  8. 8Toasts report adjustments the editor made on its own. Each has Undo, which reverts the whole command. Removals use the warning style.

Open questions

  • Export: presets only (shown), or also an "Advanced" section with bitrate and frame rate?
  • Should relinking happen silently when exactly one match is found in the project folder?
  • Fit to Music failure: offer an automatic fix, such as shortening all transitions?
  • Fit to Music: how do text clips count (shown here keeping their duration)? This is open in spec §9.
  • Keep a history of past toasts, for example a notification list in the status bar?
